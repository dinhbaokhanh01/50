# Thực hành Menu Dropdown HTML & CSS

Project gồm 2 bài thực hành:

1. Menu dropdown dọc.
2. Menu dropdown ngang.

## Cấu trúc

```text
menu-dropdown-html-css/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Chạy bài

Mở file `index.html` bằng trình duyệt.

## Yêu cầu đã thực hiện

- Menu dọc bằng HTML và CSS.
- Menu con của menu dọc được ẩn mặc định.
- Menu con của menu dọc hiển thị khi di chuột vào mục cha.
- Menu ngang bằng HTML và CSS.
- Menu con của menu ngang được ẩn mặc định.
- Menu con của menu ngang hiển thị khi di chuột vào mục cha.
- Có thể đưa project lên GitHub hoặc CodePen để nộp bài.
